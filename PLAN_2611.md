## 1. 🔴 CRÍTICO — Fórmula % Mermas/Excedencias (Resumen Diario)

### Estado actual (incorrecto)
- En `dailyActivities` y vista HTML/PDF: `% Total = SUMA de % por turno` (ej: 10+10+10=30)
- Cada turno: `% = mermas_m3 / ingreso_m3 * 100` (correcto individualmente)
- Total: suma simple → matemáticamente wrong

### Fórmula correcta (promedio ponderado por volúmenes)
```
Para cada turno:
  ingreso_m3 = puente_entrante - puente_saliente
  venta_m3   = sum(closing - opening) 6 mangueras
  mermas_m3  = ingreso_m3 - venta_m3
  pct_turno  = ingreso_m3 > 0 ? (mermas_m3 / ingreso_m3) * 100 : 0

Para TOTAL del día:
  total_ingreso_m3 = sum(ingreso_m3_turnos)
  total_mermas_m3  = sum(mermas_m3_turnos)
  pct_total        = total_ingreso_m3 > 0 ? (total_mermas_m3 / total_ingreso_m3) * 100 : 0
```

### Dónde tocar
| Archivo | Función/Sección | Qué cambiar |
|---------|----------------|-------------|
| `src/routes/operativa.ts` | `GET /operativa/resumen-diario` (cálculo `summaryRows` + `totals`) | Recalcular `totals.gncPorcentaje` con fórmula ponderada |
| `src/routes/operativa.ts` | `POST /operativa/resumen-diario/facturacion` (upsert `dailyActivities`) | Guardar `manana/tarde/noche_gnc_porcentaje` (individual) + recalcular total ponderado al leer |
| `src/routes/operativa.ts` | PDF print (`/operativa/resumen-diario/print`) | Mostrar `% Total` ponderado (ya usa `totals.gncPorcentaje`) |
| `src/db/schema.ts` | Tabla `dailyActivities` | **No tocar columnas** (ya tiene por turno + se recalcula total al leer) |

### Tests a actualizar
